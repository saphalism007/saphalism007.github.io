# Saphal's Dictionary

An advanced English vocabulary dictionary with Nepali pronunciation and Nepali
meaning for every word, built for personal study of SAT level vocabulary.

Each word shows:

- the word and its part of speech
- pronunciation written in Nepali Devanagari
- the meaning in simple English
- the meaning in Nepali
- an example sentence
- common phrases and related idioms

It also keeps saved words, a review system and short quizzes. Everything is
stored in your own browser, so nothing is sent anywhere.

The whole app is one file, `index.html`. It needs no server and no internet.

Source code lives in the `saphals-dictionary` project. Rebuild this file with
`npm run share`.
